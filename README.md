# Playwright Labs

A practical QA Automation laboratory project built with Playwright and TypeScript.

The purpose of this project is to practice and demonstrate real-world browser automation scenarios, Playwright capabilities, synchronization strategies, test design, network interception, mocking, accessibility, visual testing, and advanced Playwright Test features.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- ESLint
- Prettier
